# QSITE 2026 Quantum Coalition Open Challenges, submission of Matthew Stanley Leibel

Two entries, one idea. A stability contract holds continuous hardware in specification in-band, from one parallel
acquisition per cycle, at host cost linear in channels, so a hybrid digital/quantum system can run in high-dimensional
space in real time, continuously and unsupervised. Each track answers its own question first and then shows what the
contract does to it.

| Track | Folder | Deliverables |
|---|---|---|
| Scientific (ANNNI phase diagram under two classes of error) | `scientific_track/` | executed PennyLane notebook, three required diagrams, 3-page write-up, 9-slide presentation with timed script |
| Computational (placement and routing, 78.5 vs baseline 283.5) | `computational_track/` | `solve()`, 2-page write-up, 4-slide demo with timed script, run-time validity experiment |

Each folder has its own README with reproduction steps and a full list of references and resources used.
The maintenance layer used in both tracks is TrueLoop v3.1.0 (NEOTECH Inc.), included as a 90-day evaluation build
under its own licence (`scientific_track/trueloop/`, `computational_track/`); method and bounds are in
doi:10.20944/preprints202609.1101.v1. Everything else in this repository is released under the MIT licence.

Presentation videos: links in `VIDEOS.md`.
